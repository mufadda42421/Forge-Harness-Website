Product tour

The product is the preview.

A real, working desktop application — not mockups. Every screen below ships in Forge Harness today.

01

Chat with any registered model

OpenRouter, Anthropic, Gemini, Ollama, or any OpenAI-compatible endpoint. Streaming by default, token usage reported by the provider, persisted locally.

02

From one prompt to a fleet

Capabilities

Everything you need.
Nothing you don't.

Intelligent AI agents

Six role-based agent templates — Planner, Research, Coding, Review, Testing, Documentation — or build your own. Each with its own model, instructions, execution limits and explicit tool grants.

  • Model assignment per agent, enforced at runtime
  • Execution limits, retries and cancellable runs
  • Persisted messages and agent execution telemetry

Any model provider

100% BYOK — Anthropic, Gemini, Ollama, OpenRouter, OpenAI-compatible, custom HTTP. AES-256-GCM encrypted keys, local-first, zero telemetry.

Agent orchestration

Sequential, parallel, hierarchical, evaluator and debate patterns — all bounded, logged and cancellable.

Tools & MCP

Permissioned tool registry. Approval flows for risky operations. MCP stdio client included.

Model Arena & Benchmarks

Side-by-side comparisons across every registered model, plus deterministic substring/regex benchmark suites.

Context & Memory

User-authored context documents and memory, injected only when relevant — never silently uploaded.

Visual workflow builder

Acyclic graphs validated before execution. Condition nodes, approval checkpoints, resumable runs.

Execution monitoring

Tokens, latency, retries and cost estimates — measured from provider-reported usage. Never invented.

Measured, not guessed.

Analytics computed locally from your own rows — no vanity metrics, no invented numbers.
